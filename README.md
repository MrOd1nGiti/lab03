# Лабораторная работа 3. Условия и логические выражения

## Запуск программ
Каждая программа запускается через терминал:
- python minimum.py
- python calculator.py
- python point.py
- python variant.py

---

## Проверки и результаты

### 1. Минимум трёх чисел (minimum.py)
- Входные данные: 2, 10, 3 -> Результат: 2
- Входные данные: 5, 5, 5 -> Результат: 5
- Входные данные: -4, 0, -2 -> Результат: -4
- Входные данные: 10, 3, 1 -> Результат: 1 (минимум на последней позиции)

### 2. Калькулятор (calculator.py)
- Входные данные: 7, 2, / -> Результат: 3.50
- Входные данные: 5, 0, / -> Результат: Деление на ноль запрещено
- Входные данные: 5, 2, ? -> Результат: Неизвестная операция
- Входные данные: 4, 3, + -> Результат: 7.00

### 3. Принадлежность прямоугольнику (point.py)
- Входные данные: 2, 2 -> Результат: Внутри или на границе
- Входные данные: 5, 3 -> Результат: Внутри или на границе
- Входные данные: 5.1, 3 -> Результат: Снаружи

### 4. Индивидуальный вариант 1: Заряд аккумулятора и високосный год (variant.py)
- Входные данные (заряд): -1 -> Результат: Ошибка диапазона
- Входные данные (заряд): 0, 19, 20, 79, 80, 100, 101 -> Результат: Низкий (0-19), Средний (20-79), Высокий (80-100), Ошибка для 101
- Входные данные (год): 1900 -> Результат: нет
- Входные данные (год): 2000 -> Результат: да
- Входные данные (год): 2024 -> Результат: да
- Входные данные (год): 2023 -> Результат: нет
